**Parim valik talveks:**

## ⚠️ Mida jälgida paketi valimisel?

### 1. Marginaal vs Kuutasu

**Väike tarbimine (<200 kWh):**
- Marginaal pole nii oluline
- Kuutasu on suur osa kulust
- ✅ Vali **madal kuutasu**

**Suur tarbimine (>500 kWh):**
- Kuutasu pole nii oluline
- Marginaal on suur osa kulust
- ✅ Vali **madal marginaal**

**Näide:**
```
Väike (150 kWh):
Alexela (0,457s + 1,99€) = 0,457×150 + 1,99 = 68,55 + 1,99 = 70,54€
Elenger (0,67s + 0€) = 0,67×150 + 0 = 100,50€
→ Alexela odavam!

Suur (1000 kWh):
Alexela (0,457s + 1,99€) = 0,457×1000 + 1,99 = 457 + 1,99 = 458,99€
Elenger (0,67s + 0€) = 0,67×1000 + 0 = 670€
→ Alexela ikkagi odavam (madalam marginaal!)
```

## 🔮 Tuleviku trendid

### 1. 15-minutilised börsihinnad (alates okt 2025)

**Muudatus:**
- Seni: 1 tunni hinnad
- Tulevikus: 15-minuti hinnad

**Mõju:**
- Täpsem hinnakujundus
- Tarbid odaval ajal → säästad rohkem
- Tarbiid kallil ajal → maksad rohkem
